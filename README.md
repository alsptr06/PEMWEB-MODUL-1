# Modul 1: Praktikum Pemrograman Web (Penggunaan Git)

## 📌 Deskripsi Proyek
Proyek ini merupakan aplikasi **Web Calculator** sederhana berbasis web yang dibangun menggunakan **Next.js** dan **Tailwind CSS**. Aplikasi ini dibuat untuk memenuhi tugas Praktikum Pemrograman Web (Modul 1: Penggunaan Git), yang memungkinkan pengguna melakukan operasi matematika dasar secara interaktif melalui antarmuka web.

## 🚀 Fitur
- Operasi aritmatika dasar: penjumlahan (`+`), pengurangan (`-`), perkalian (`×`), dan pembagian (`÷`).
- Fitur reset / clear (`C` / `AC`) untuk mengulang perhitungan.
- Antarmuka responsif dan ramah pengguna.

## 🛠️ Cara Menjalankan Proyek
1. **Install dependensi:**
   ```bash
   npm install
   ```
2. **Jalankan development server:**
   ```bash
   npm run dev
   ```
3. **Buka di browser:**
   Akses [http://localhost:3000](http://localhost:3000) untuk melihat aplikasi.

## 📖 Cara Penggunaan Singkat
1. Buka aplikasi di browser melalui `http://localhost:3000`.
2. Masukkan angka pertama dengan mengklik tombol angka pada kalkulator.
3. Pilih tombol operasi matematika yang diinginkan (`+`, `-`, `×`, atau `÷`).
4. Masukkan angka kedua/berikutnya.
5. Tekan tombol **`=`** untuk melihat hasil perhitungan.
6. Tekan tombol **`C`** atau **`AC`** untuk membersihkan layar dan memulai perhitungan baru.
